# 午市厨房

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查及生产构建：

```sh
npm run typecheck
npm run build
```

挑战赛事核心逻辑验证（确定性、流水重算、冲突检测、解锁与版本）：

```sh
npm run verify
```

## 本地挑战赛事

左侧导航「🏆 赛事」进入挑战大厅：

- **关卡**：每关限定初始库存、来客表、设备与胜利条件（限时营业 + 净收益 + 浪费上限 + 满意度下限），同一关重复开始来客与事件完全相同。
- **预演 / 正式**：预演不刷新纪录、不消耗正式次数；正式成绩只由订单、食材消耗、火候与交付流水重算，修改显示分无法过关。
- **关卡编辑器**：可新建或复制内置关卡，组合目标互相矛盾或资源上无法完成时会给出具体冲突（设备缺失、理论收益上限、必然浪费、满意度/限时不可达、解锁循环）。
- **解锁**：支持多条前置路线（任一路线通关即解锁），不允许循环，失败不计通关。
- **版本**：正式局中修改关卡只生成下次生效的新版本，结算标明所用版本与达成依据。

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。
